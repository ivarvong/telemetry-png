This repository contains two independently generated Commit Mono font atlases:

- `otel-png-font.mjs` was generated by `tools/build-font.py` from `CommitMono-400-Regular.otf` and `CommitMono-700-Regular.otf`. Those source OTF files are not vendored, and their exact Commit Mono version was not recorded; this repository therefore does not claim one.
